### 👾 About Me

I'm a cybersecurity and DevSecOps engineer based in Tunisia. My work sits at the intersection of platform engineering and applied security — building the pipelines and guardrails that let teams ship fast *without* shipping vulnerabilities.

My thesis project — **Secure DevSecOps Platform for ERP Cloud Service Industrialization** — is a production-grade K3s platform running six services (Odoo, ERPNext, Nextcloud, Mautic, WordPress, n8n) behind a full security stack: HashiCorp Vault for secrets, Cilium + Traefik + CrowdSec at the network edge, Wazuh for SIEM, and a 13-stage Jenkins pipeline wired through ArgoCD for GitOps — with SAST/SCA/DAST (Gitleaks, Semgrep, Trivy, Checkov, Kubescape, OWASP ZAP) gating every deploy.

🔐 **Cybersecurity & DevSecOps** | ☁️ **Cloud & Kubernetes Security** | 🛡️ **Certified:** Cisco · AWS · RHCSA

**Goals:** Landing my first full-time role as a DevSecOps or Cloud Security Engineer — Tunisia/MENA first, open to remote and EU.
